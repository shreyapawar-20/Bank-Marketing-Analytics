# Bank Marketing Analytics Dashboard

**Subject:**Marketing Campaign Performance  
**Topic:** Interactive Excel Dashboard for Bank Marketing and Subscription Analysis

# Project Overview

This project focuses on analyzing bank marketing campaign data using Microsoft Excel. The interactive dashboard helps understand customer demographics, subscription performance, and customer segmentation through KPIs, PivotCharts, and interactive slicers.

The dashboard provides a clear overview of customer subscription behavior and supports data-driven marketing decisions.

# Project Objectives

- Analyze bank marketing campaign performance.
- Monitor customer and subscription metrics.
- Compare subscription outcomes across job, education, and marital-status groups.
- Create an interactive dashboard using Excel PivotTables, PivotCharts, and slicers.
- Identify opportunities to improve subscription rates.
- Present numerical insights and recommendations for marketing strategy improvement.

# Tools and Technologies

- Microsoft Excel
- PivotTables
- PivotCharts
- Interactive Slicers
- Excel formulas and KPI calculations
- Data analysis and visualization

# Dashboard KPIs

The dashboard displays the following key performance indicators:

| KPI | Displayed Value |

| Total Customers | 10,000 |
| Successful Subscriptions | 1,192 |
| Subscription Rate | 12% |
| Average Balance | 1,369 |


# Dashboard Features

### 1. Subscription by Job
Analyzes subscription outcomes across different job categories to compare customer responses to marketing campaigns.

### 2. Subscription Status
Displays the distribution of customers who subscribed successfully (`Yes`) and those who did not (`No`).

### 3. Subscription by Education
Compares subscription outcomes across education groups to identify differences in customer response.

### 4. Subscription by Marital Status
Examines subscription distribution across marital-status groups.

### 5. Interactive Slicers
The dashboard includes slicers for:
- Job
- Education
- Marital Status

These filters allow users to explore customer segments and analyze the dashboard interactively.

# Key Insights

- The dashboard displays a subscription rate of **12%**.
- A total of **1,192 successful subscriptions** are displayed.
- Job, education, and marital-status categories can be compared to investigate differences in subscription performance.
- Segment-level subscription rates should be examined alongside customer counts to identify the strongest and weakest-performing groups.

# Recommendations

### 1. Improve the Overall Subscription Rate
**Current displayed rate:** 12%  
**Proposed target:** 15%

The bank can test improved campaign messaging, follow-up strategies, and customer targeting to work toward the proposed target.

If the customer base remains at 10,000, a 15% subscription rate would mean 1,500 subscriptions. Compared with the current displayed count of 1,192, this represents **308 additional subscriptions**.

### 2. Improve Job-Based Targeting
Compare subscription rates across job categories. Test targeted marketing campaigns for lower-performing groups and measure whether their subscription rates improve.

### 3. Personalize Education-Based Campaigns
Compare subscription rates across education groups and test customized messages for segments with lower subscription rates.

### 4. Review Marital-Status Segments
Analyze subscription rates across marital-status groups and test different campaign approaches where improvement opportunities are identified.

*Note: The 15% subscription rate is a proposed target, not a guaranteed outcome. Segment-specific findings should be supported by actual numerical results from the dashboard.*
